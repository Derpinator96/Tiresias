# site/web: notes

Owner: humans

Purpose: new front end. Basic Next.js app, no pages built yet. Full project context: docs/frontend-context.md.

## Decisions

- 2026-10-04: a human asked for a basic Next.js app. Scaffolded with create-next-app (TypeScript, Tailwind, App Router, src/, npm, Turbopack), then shadcn init with these components: button, card, tabs, table, badge, progress, slider, chart (Recharts), dialog, alert, separator, tooltip, scroll-area, sonner, switch, toggle-group, sheet. Extra packages: lucide-react (icons, no emoji), @xyflow/react (plan trees). Dev: `npm --prefix site/web run dev -- --port 5173`, also in .claude/launch.json.
- 2026-10-04: an earlier Vite and React attempt in this folder was deleted at a human's request. A first Vite walkthrough page (nine steps, real figures from run_d1b30d38) was replaced by this scaffold.
- 2026-10-04: the shadcn defaults (radius, colors, button shapes) are not yet checked against CLAUDE.md: no pill buttons, no purple.
- This app is not wired into make site. It would show real names if fed gateway data, so it stays local until a human decides what is public.
- 2026-10-04: /playground built at a human's request: an @xyflow/react canvas of the 8 stages, a zustand step machine (src/lib/store.ts: run, pause, step forward and back, reset, 1x 2x 5x), and an inspector drawer per stage. / redirects to it. zustand 5 added as a direct dependency (4.x was only transitive via @xyflow).
- 2026-10-04: every figure comes from src/data/run_d1b30d38.json (exact copy of runs/latest.json, which is gitignored) or names its source in src/lib/facts.ts. The request asked for figures the run record does not hold; they are shown as "not in run record" instead: template id, candidate counts, the Q-table, the order and payloads of the 5 tool calls (the request said 8: 8 is the number of tools, 5 the calls), plan node breakdown, checksum hash values (the requested md5:d41d8cd98f... is the MD5 of an empty string), per-payload ledger rows, config_id.
- 2026-10-04: the requested "write overhead under 5%" gate is not met by the data: +0.032 ms against a 0.23 to 0.51 ms insert is 6% to 14% (db/NOTES.md). The gate reads "Write cost reviewed" with those figures.
- 2026-10-04: the Q-table is a sandbox: cells start at config.yaml rl.q_init and change only by the viewer's Bellman updates (same line as rl/search.py, STOP has target 0). alpha and gamma default to config.yaml values copied into src/lib/facts.ts; the browser cannot read config.yaml. Replay pacing (1200 ms per stage / speed) is a UI constant, not a measured time, and is labelled as such on screen.
- 2026-10-04: live hydration tries GET {NEXT_PUBLIC_GATEWAY_URL or http://localhost:8000}/v1/ledger. Compose does not publish the gateway port and the gateway sends no CORS headers, so this falls back to the run record today (one ERR_CONNECTION_REFUSED in the console). The AI service (port 8100 inside Compose, not 8001) is not called: it has no read-only endpoint the page needs.
- 2026-10-04: migration.sql and rollback.sql are rendered by hand from gateway/approve.py build() for one add_index action. "Authorize deployment" records the decision in the browser only and sends nothing. Copy uses navigator.clipboard (the desktop app's browser pane blocks it and the page shows an error toast); Download patch archive writes a ustar file (src/lib/logic.ts tar, tested).
- 2026-10-04: the page shows real table and column names and the raw Q1 SQL, so it must not go public as is (site/NOTES.md: the public site never shows them). badge.tsx changed from rounded-4xl to rounded-md (no pill shapes). globals.css: --font-sans pointed at itself; now --font-geist-sans.
- 2026-10-04: review pass. Fixed: nodes were controlled with no change handler, so dragging did nothing (now defaultNodes/defaultEdges); zoom and lock controls sat under the open inspector (moved bottom-left, log beside them); downloads revoked the blob URL synchronously (now after 1 s); copy falls back to a hidden textarea when the Clipboard API is blocked (a real click in the browser pane now shows "Copied"); Escape closes the inspector; toolbar wraps at phone width. The default Next favicon and starter SVGs were removed; src/app/icon.svg is site/favicon.svg. devIndicators off in next.config.ts (it covered the replay log).
- 2026-10-04: the app became the website (human decision, plan in the session): home, /playground, /stages/[slug] for the 8 stages (copy and sourced figures in src/lib/stages.ts, interactive section reuses the playground's inspector sheets), /hashing visualizer, /ask, /privacy, /terms. It replaces the static site/ as the public Vercel deploy once a human switches it (root directory site/web, no env vars).
- 2026-10-04: public pages show no real names of the demo database. facts.ts uses one illustrative code map (t_7a3f91c2 ...), labelled "illustrative codes, not the gateway's real ones". The playground no longer calls localhost (hydrate removed). scripts/tests/test_export_and_site.py scans the build (server HTML and RSC, own source, client chunks) for the forbidden names, canaries, dashes and builder text, checks every page links privacy and terms, and that 14 routes prerender; `make test-web` builds in a node container and runs it.
- 2026-10-04: glassmorphism system: tokens on :root in globals.css (--glass-*), shadcn tokens point at them, one @layer components block gives every shadcn surface blur and shadow by data-slot, utilities glass, glass-strong, glass-subtle, glass-bar, inset-field, and .stage-card for playground nodes. Light only: the dark variant applies only under a .dark class that is never set. Added shadcn components: accordion, input, textarea, checkbox, label, navigation-menu, collapsible.
- 2026-10-04: hashing visualizer (src/lib/hashing.ts): Web Crypto HMAC-SHA256 with a demo key made in the tab, same code format as gateway/hashing.py, values to ?, roles as gateway/strip.py. SIMPLIFIED (labelled): a tokenizer, not sqlglot, and no catalog, so an unqualified column with two tables in scope fails closed. tests/hashing.test.mjs checks it against Python hmac and node:crypto.
- 2026-10-04: live Ask (local only): src/lib/ask-shared.ts ports dashboard/home.py run_job and dashboard/data.py sql_statements (tests/ask.test.mjs with fakes); src/lib/ask-server.ts and app/api/ask/route.ts run it, 404 unless BT_LOCAL=1, 403 on a Host not in BT_WEB_HOSTS or a non-JSON POST; timeouts from config.yaml web.* (mounted read-only, read with js-yaml). The page imports "bt-live-ask", which next.config.ts resolves to the live component only when NEXT_PUBLIC_BT_LOCAL=1 (the Dockerfile sets it) and to a null stub otherwise: a plain dynamic import still emitted an orphan chunk with the live code, which the scan caught.
- 2026-10-04: live Ask was tested against fake services (a scratch node server), not the real stack: Docker is not reachable from the agent session. Guards checked with curl (forged Host 403, form post 403, empty question 400, unknown id 404); the browser flow showed progress, the dehashed answer, the AI view, twin result, SQL and rollback.
- 2026-10-04: /ask replays src/data/ask_replay.json, written by `make record-ask` (scripts/record_ask.py, hashed only, refuses on a forbidden name or canary). It holds a labelled placeholder until a human records a run; publishing real HMAC codes there is approved (2026-10-04).
- 2026-10-04: privacy and terms ported from site/src and updated for a JS site (self-hosted fonts and scripts, the visualizer runs in the browser); both need human review before deploy. npm audit reports 9 high-severity advisories in the dependency tree (not investigated; most come with the shadcn CLI package).
