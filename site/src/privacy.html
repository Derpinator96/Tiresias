Privacy policy for this website

Last updated 3 October 2026. This policy covers this website only, not the Blind Tuner software.

This site collects nothing itself

The site is a set of static pages. It has no accounts, no forms, no comments, no cookies, no analytics, no tracking pixels and no third-party scripts. It loads no fonts, images or code from other servers. It has no connection to any database, and it never receives the demo database or any data from it.

The hosting provider processes request data

The site is hosted on Vercel. To deliver pages and protect the service, Vercel receives standard request information, such as your IP address, browser user agent and the page requested, and may keep it in logs. Vercel handles that data under its own privacy policy: vercel.com/legal/privacy-policy. We do not receive those logs unless we look at them in the hosting dashboard, and we do not combine them with anything else.

Numbers on the results page come from synthetic data

The results page shows measurements from a demo database generated for this project. It holds no real person's data.
